## ⚠️ Important Notes

### **Best Practices**
1. ✅ Always verify emails before sending
2. ✅ Personalize every message
3. ✅ Respect opt-out requests immediately
4. ✅ Follow up once after 7 days, then stop
5. ✅ Don't send more than 50 emails/day initially

### **Legal Compliance**
- **CAN-SPAM Act** (US): Include unsubscribe link
- **GDPR** (EU): Only email with consent or legitimate interest
- **CASL** (Canada): Express consent required

### **Email Reputation**
- Use professional domain (not Gmail)
- Set up SPF, DKIM, DMARC records
- Warm up new domains slowly
- Keep bounce rate < 3%
- Monitor spam complaints
